# JavaScript - Objects, Scopes and Closures

Classes, inheritance, and closures in JavaScript: building a
`Rectangle`/`Square` class hierarchy and a handful of small
scope/closure exercises.

## Requirements

- Interpreted on Ubuntu 20.04 LTS using Node.js (version 14.x)
- All files end with a new line
- The first line of every file is exactly `#!/usr/bin/node`
- Code follows the `semistandard` style (Standard + semicolons)
- All files are executable
- No use of `var`

## Tasks

| File | Description |
| --- | --- |
| `0-rectangle.js` | Empty `Rectangle` class |
| `1-rectangle.js` | `Rectangle` with `width`/`height` from the constructor |
| `2-rectangle.js` | Same, but invalid `width`/`height` create an empty object |
| `3-rectangle.js` | Adds a `print()` method |
| `4-rectangle.js` | Adds `rotate()` and `double()` methods |
| `5-square.js` | `Square` extending `Rectangle` via `super()` |
| `6-square.js` | `Square` extending `5-square.js`, adds `charPrint(c)` |
| `7-occurrences.js` | Counts occurrences of an element in a list |
| `8-esrever.js` | Reverses a list without using `.reverse()` |
| `9-log.js` | Logs each call with a running call count (closure) |
| `10-converter.js` | Converts a base-10 number to another base |
