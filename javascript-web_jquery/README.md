# JavaScript - Web jQuery

DOM manipulation and events with jQuery: selecting elements, styling,
classes, list manipulation, and fetching data from external APIs.

## Requirements

- Interpreted on Chrome (version 57.0)
- All files end with a new line
- Code follows the `semistandard` style, run with the `--global: $`
  flag (`semistandard *.js --global $`)
- jQuery version 3.x
- No use of `var`
- No full-page reload for any action (DOM manipulation, fetching data)

## Tasks

| File | Description |
| --- | --- |
| `0-script.js` | Turns the header text red (vanilla JS, `document.querySelector`) |
| `1-script.js` | Same, but with jQuery instead |
| `2-script.js` | Turns the header red on click |
| `3-script.js` | Adds a `red` class to the header on click |
| `4-script.js` | Toggles the header between `red` and `green` classes |
| `5-script.js` | Appends a new `<li>` to a list on click |
| `6-script.js` | Changes the header's text on click |
| `7-script.js` | Fetches a Star Wars character's name and displays it |
| `8-script.js` | Fetches and lists all Star Wars movie titles |
| `9-script.js` | Fetches a French translation of "hello" and displays it |
