# JavaScript - Web scraping

Small scripts covering file I/O (`fs`) and basic HTTP requests
(`request`) in JavaScript: reading/writing files, checking a URL's
status code, and pulling data from a couple of public APIs (the Star
Wars API and JSONPlaceholder).

## Requirements

- Interpreted on Ubuntu 20.04 LTS using Node.js (version 10/14.x)
- All files end with a new line
- The first line of every file is exactly `#!/usr/bin/node`
- Code follows the `semistandard` style (Standard + semicolons)
- All files are executable
- No use of `var`

## Tasks

| File | Description |
| --- | --- |
| `0-readme.js` | Reads and prints the content of a file |
| `1-writeme.js` | Writes a string to a file |
| `2-statuscode.js` | Prints the status code of a URL request |
| `3-starwars_title.js` | Prints a Star Wars movie title by episode ID |
| `4-starwars_count.js` | Counts films featuring Wedge Antilles |
| `5-request_store.js` | Fetches a webpage and stores it in a file |
| `6-completed_tasks.js` | Counts completed tasks per user ID |
