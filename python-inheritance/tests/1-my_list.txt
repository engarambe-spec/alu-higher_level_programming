The ``1-my_list`` module
========================

Using MyList
------------
::

    >>> MyList = __import__('1-my_list').MyList

Create a MyList and append elements::

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]

print_sorted() prints a sorted copy, without modifying the original::

    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

An empty list prints as an empty list::

    >>> MyList().print_sorted()
    []
