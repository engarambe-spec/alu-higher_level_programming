# JavaScript - Warm up

A series of small JavaScript scripts covering the basics of the
language: variables, arguments, conditionals, loops, functions,
recursion, and objects.

## Requirements

- Interpreted on Ubuntu 20.04 LTS using Node.js (version 14.x)
- All files end with a new line
- The first line of every file is exactly `#!/usr/bin/node`
- Code follows the `semistandard` style (Standard + semicolons)
- All files are executable
- No use of `var`

## Tasks

| File | Description |
| --- | --- |
| `0-javascript_is_amazing.js` | Prints a constant string |
| `1-multi_languages.js` | Prints 3 fixed lines |
| `2-arguments.js` | Prints a message based on the number of arguments |
| `3-value_argument.js` | Prints the first argument passed |
| `4-concat.js` | Prints two arguments in `"<a> is <b>"` format |
| `5-to_integer.js` | Converts the first argument to an integer |
| `6-multi_languages_loop.js` | Prints 3 lines using an array and a loop |
| `7-multi_c.js` | Prints `"C is fun"` N times |
| `8-square.js` | Prints a square of `X` characters |
| `9-add.js` | Adds two integers via an `add` function |
| `10-factorial.js` | Computes a factorial recursively |
| `11-second_biggest.js` | Finds the second biggest integer among arguments |
| `12-object.js` | Mutates a `const` object's property |
| `13-add.js` | Exports an `add` function for use in other files |
