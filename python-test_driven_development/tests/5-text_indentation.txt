The ``5-text_indentation`` module
====================================

Import the function:

    >>> text_indentation = __import__('5-text_indentation').text_indentation

Regular string with periods:

    >>> text_indentation("Holberton School")
    Holberton School

String with a period followed by more text:

    >>> text_indentation("Holberton.School")
    Holberton.
    <BLANKLINE>
    School

String with multiple special characters (., ? and :):

    >>> text_indentation("Holberton. School? How are you: John")
    Holberton.
    <BLANKLINE>
    School?
    <BLANKLINE>
    How are you:
    <BLANKLINE>
    John

Non-string input raises a TypeError:

    >>> text_indentation(12)
    Traceback (most recent call last):
    TypeError: text must be a string

An empty string prints nothing:

    >>> text_indentation("")

A string that is only whitespace prints nothing:

    >>> text_indentation("   ")

There is no space at the beginning or end of each printed line:

    >>> text_indentation("Hello.   World?")
    Hello.
    <BLANKLINE>
    World?
    <BLANKLINE>
