The ``2-matrix_divided`` module
=================================

Using matrix_divided
----------------------
::

    >>> matrix_divided = __import__('2-matrix_divided').matrix_divided

Dividing a basic 2x3 matrix::

    >>> matrix_divided([[1, 2, 3], [4, 5, 6]], 3)
    [[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]

The original matrix is not modified::

    >>> matrix = [[1, 2, 3], [4, 5, 6]]
    >>> result = matrix_divided(matrix, 3)
    >>> matrix
    [[1, 2, 3], [4, 5, 6]]

Dividing with a float divisor::

    >>> matrix_divided([[1, 2], [3, 4]], 2.5)
    [[0.4, 0.8], [1.2, 1.6]]

A matrix containing floats::

    >>> matrix_divided([[1.5, 2.5], [3.5, 4.5]], 2)
    [[0.75, 1.25], [1.75, 2.25]]

A single-row matrix::

    >>> matrix_divided([[6, 9]], 3)
    [[2.0, 3.0]]

Dividing by 1 leaves values unchanged (as floats)::

    >>> matrix_divided([[1, 2]], 1)
    [[1.0, 2.0]]
